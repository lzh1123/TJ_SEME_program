# Slideon 用户手册

版本：1.1  
适用对象：第一次使用 Slideon 网站的普通用户  
编写日期：2026-07-02

## 1. 欢迎使用 Slideon

Slideon 是一个在线智能 PPT 生成网站。你只需要输入一个主题，或上传一份文档，系统就可以帮你生成 PPT 大纲，并把大纲转换成演示文稿页面。你还可以在网站中编辑大纲、管理资料、查看生成结果，并下载可继续编辑的文件。

本手册面向没有技术基础的用户，按实际使用顺序介绍每个功能。你只需要按照页面提示操作即可。

![图 0 未登录首页](../res/picture/未登录页面.png)

## 2. 开始之前

### 2.1 你需要准备什么

使用 Slideon 前，请准备：

| 准备项 | 说明 |
| --- | --- |
| 浏览器 | 推荐使用 Chrome、Edge 或其他现代浏览器 |
| 网络连接 | 生成大纲、上传资料和登录都需要联网 |
| 账号 | 保存大纲、管理知识库、查看个人资料时需要登录 |
| PPT 主题 | 例如“人工智能在教育中的应用”“新能源汽车行业分析” |
| 可选资料 | PDF、DOCX、PPTX、TXT、Markdown 等文档可用于生成或知识库增强 |

### 2.2 网站主要页面

| 页面 | 你可以做什么 |
| --- | --- |
| 首页 | 开始生成 PPT 大纲 |
| 登录 / 注册 | 创建账号并登录 |
| 我的大纲 | 查看、搜索、编辑或删除已保存的大纲 |
| 大纲编辑器 | 修改 PPT 结构、页面类型和每页内容 |
| PPT 编辑器 | 查看生成后的 PPT 页面 |
| 知识库 | 上传资料，让 AI 参考你的文档生成内容 |
| 个人资料 | 查看账号信息、修改显示名称、查看可用模型 |

## 3. 注册、登录与退出

### 3.1 注册新账号

1. 打开 Slideon 网站。
2. 点击右上角“注册”。
3. 输入用户名、邮箱、密码和显示名称。
4. 点击“创建账号”。
5. 页面提示注册成功后，会自动跳转到登录页。

![图 1 注册账号页面](../res/picture/注册账号.png)

注意：

- 用户名用于登录和识别账号。
- 邮箱需要填写有效格式。
- 密码请妥善保管。

### 3.2 登录账号

1. 点击右上角“登录”。
2. 输入用户名或邮箱。
3. 输入密码。
4. 点击“登录”。
5. 登录成功后，右上角会显示头像入口。

![图 2 登录账号页面](../res/picture/登录账号.png)

如果登录失败，请检查用户名、邮箱或密码是否输入正确。

### 3.3 查看和修改个人资料

1. 登录后点击右上角头像。
2. 进入“个人信息”页面。
3. 在“编辑资料”中修改显示名称。
4. 点击“保存修改”。

![图 3 查看和修改个人信息](../res/picture/查看修改个人信息.png)

个人资料页还会显示：

- 当前登录状态。
- 用户名和邮箱。
- 平台大模型是否可用，例如 DeepSeek、Qwen、GLM。

### 3.4 退出登录

1. 进入“个人信息”页面。
2. 点击“退出登录”。
3. 系统会回到未登录状态。

退出后，你仍可以浏览首页，但保存大纲、上传知识库等功能需要重新登录。

## 4. 从主题生成 PPT 大纲

这是最常用的功能。适合你已经知道要做什么主题，但还没有 PPT 结构。

### 4.1 打开生成窗口

你可以从以下入口打开生成窗口：

- 首页点击“开始生成”。
- 顶部导航栏点击“创建”。
- “我的大纲”页面点击“新建大纲”或“开始创建”。

打开后，会看到“智能生成大纲”窗口。

![图 4 大纲生成入口界面](../res/picture/大纲生成界面.png)

### 4.2 选择“主题生成”

1. 在生成窗口中选择“主题生成”。
2. 在文本框中输入 PPT 主题。
3. 主题最多 500 字，建议写清楚用途、听众和重点内容。

示例：

```text
为大学课堂汇报准备一份 PPT，主题是“人工智能在教育中的应用”，重点介绍应用场景、优势、风险和未来趋势。
```

![图 5 主题生成示例](../res/picture/主题生成示例.png)

### 4.3 设置 RAG 增强

在主题生成模式下，你会看到“混合 RAG 增强（知识库 + 网络搜索）”开关。

| 状态 | 适用情况 |
| --- | --- |
| 开启 | 希望 AI 参考知识库和网络资料，生成更专业、更具体的内容 |
| 关闭 | 希望快速生成，或网络搜索较慢时 |

如果你已经在知识库上传过课程资料、报告或参考文档，建议开启 RAG。

### 4.4 生成大纲

1. 确认主题已填写。
2. 点击“生成大纲”。
3. 等待系统生成。生成过程中按钮会显示“生成大纲中...”。
4. 生成完成后，系统会进入“大纲编辑器”。

![图 6 等待生成大纲](../res/picture/等待生成大纲.png)

如果生成时间较长，请不要重复点击按钮。若生成失败，可以稍后重试，或关闭 RAG 后再生成。

## 5. 从文档生成 PPT 大纲

如果你已经有论文、报告、课程材料或现成 PPT，可以用“文档生成”功能。

### 5.1 上传文档

1. 打开“智能生成大纲”窗口。
2. 选择“文档生成”。
3. 点击上传区域。
4. 选择本地文件。

![图 7 文档生成大纲](../res/picture/文档生成大纲.png)

支持的文件类型包括：

- PDF
- DOCX
- PPTX
- TXT
- Markdown

### 5.2 生成大纲

1. 文件上传后，确认文件名显示正确。
2. 点击“生成大纲”。
3. 系统会读取文档内容，并生成 PPT 大纲。
4. 生成完成后，进入“大纲编辑器”。

建议上传内容清晰、结构完整的文档。扫描版 PDF 或图片型文档可能无法被完整读取。

## 6. 管理“我的大纲”

“我的大纲”用于保存和管理你已经生成或编辑过的大纲。

### 6.1 查看大纲列表

1. 登录后点击顶部导航栏“我的大纲”。
2. 页面会显示已保存的大纲卡片。
3. 每个卡片会显示标题、更新时间等信息。

![图 8 我的大纲列表](../res/picture/大纲列表.png)

如果没有大纲，页面会提示“还没有大纲”，可以点击“开始创建”生成第一份大纲。

### 6.2 搜索大纲

1. 在搜索框中输入关键词。
2. 系统会筛选匹配的大纲。
3. 如果没有结果，可以点击“清除搜索”恢复列表。

![图 9 搜索大纲](../res/picture/搜索大纲.png)

### 6.3 编辑大纲

1. 在大纲卡片上点击“编辑”按钮，或直接点击大纲卡片。
2. 页面进入“大纲编辑器”。
3. 修改后点击“保存”。

### 6.4 删除大纲

1. 在大纲卡片上点击删除按钮。
2. 系统会弹出确认窗口。
3. 点击“删除”后，大纲会被移除。

![图 10 删除大纲](../res/picture/删除大纲.png)

删除操作不可恢复，请确认不再需要该大纲。

## 7. 使用大纲编辑器

大纲编辑器是整理 PPT 结构的核心页面。左侧是页面列表，右侧是当前页面的详细内容。

![图 11 编辑大纲](../res/picture/编辑大纲.png)

### 7.1 修改演示文稿基本信息

在顶部或编辑区域中，你可以修改：

- PPT 标题。
- 受众。
- 表达语气。
- 主题样式。

修改后点击“保存”。

### 7.2 添加页面

1. 点击左侧“添加页”。
2. 系统会新增一页。
3. 选中新页面后，在右侧填写内容。

### 7.3 调整页面顺序

在左侧页面列表中，每页旁边有上移、下移按钮。

1. 选择要调整的页面。
2. 点击上移或下移。
3. 调整到合适位置后点击“保存”。

### 7.4 删除页面

1. 在左侧页面列表中找到要删除的页面。
2. 点击删除按钮。
3. 至少需要保留一页，系统会阻止删除最后一页。

### 7.5 选择页面类型

每一页都有一个“页面类型”。不同类型适合不同内容：

| 页面类型 | 适合内容 |
| --- | --- |
| 封面 | PPT 标题、副标题、亮点 |
| 目录 | 展示汇报结构 |
| 文本 | 段落、要点说明 |
| 时间线 | 发展过程、历史阶段、项目进度 |
| KPI | 指标、数字、成果 |
| 对比 | 两个方案、产品或观点的比较 |
| SWOT | 优势、劣势、机会、威胁分析 |
| 路线图 | 阶段规划、未来计划 |
| 流程 | 步骤、工作流、方法过程 |
| 图表 | 柱状图、折线图、饼图等数据表达 |
| 多列 | 多个并列观点 |
| 架构 | 系统结构、层级关系 |
| 引用 | 观点句、总结语 |
| 分隔页 | 章节过渡 |
| 团队 | 成员、角色、分工 |

切换页面类型后，右侧会出现对应的填写项。

![图 12 选择页面类型](../res/picture/选择页面类型.png)

### 7.6 编辑页面内容

选中某一页后，可以在右侧修改：

- 标题。
- 章节名。
- 段落。
- 要点。
- 图表标签和数据。
- 时间线事件。
- KPI 指标。
- SWOT 四象限。
- 团队成员和角色。
- 备注。

对于列表类内容，可以点击“添加”增加一条，也可以点击删除图标移除一条。

### 7.7 保存大纲

编辑完成后点击右上角“保存”。页面提示“保存成功”后，修改才会被记录。

也可以使用快捷键 `Ctrl + S` 保存。

![图 13 保存大纲](../res/picture/保存大纲.png)

### 7.8 下载大纲

点击右上角“下载”，可以选择：

- 下载 JSON。
- 下载 Markdown。

JSON 适合保留结构化数据，Markdown 适合查看或提交文字版大纲。

![图 14 下载大纲](../res/picture/下载大纲.png)

### 7.9 生成 PPT

1. 检查每一页标题和内容。
2. 点击右上角“生成 PPT”。
3. 系统会把大纲转换为 PPT 页面。
4. 完成后进入 PPT 编辑器查看生成结果。

![图 15 生成 PPT](../res/picture/PPT生成.png)

## 8. 查看生成后的 PPT

PPT 编辑器用于查看生成后的演示文稿页面。

### 8.1 页面布局

PPT 编辑器通常包含：

- 顶部工具栏：返回、返回主页、标题输入、保存。
- 左侧栏：大纲或页面缩略图。
- 中间区域：当前 PPT 页面预览。
- 底部工具栏：页面切换、缩放等查看操作。

### 8.2 切换页面

你可以用两种方式切换页面：

1. 在左侧“大纲”中点击某一页。
2. 在左侧“页面”缩略图中点击某一页。

### 8.3 修改标题并保存

1. 在顶部标题输入框中修改 PPT 标题。
2. 点击“保存”。

当前页面主要用于查看生成效果和基础保存。如果需要重新调整内容，建议返回大纲编辑器修改后重新生成。

### 8.4 导出 PPTX

系统支持生成可下载的 PPTX 文件。若页面提供“导出”入口，可直接点击导出；如果当前界面没有显示导出按钮，可联系项目维护者或通过系统提供的导出能力获取文件。

下载后的 PPTX 可以用 PowerPoint 或 WPS 打开继续编辑。

## 9. 使用知识库

知识库用于保存你的参考资料。开启 RAG 生成时，AI 会参考知识库内容，让 PPT 更贴合你的资料。

### 9.1 进入知识库

1. 登录账号。
2. 点击顶部导航栏“知识库”。
3. 页面会显示知识库统计、已导入文档和上传入口。

![图 16 知识库界面](../res/picture/知识库界面.png)

未登录时，页面会提示“登录后上传文档”。

### 9.2 上传资料

1. 点击“导入文档”。
2. 选择一个或多个文件。
3. 也可以把文件拖拽到上传区域。
4. 上传后，页面会显示处理进度。

![图 17 上传资料](../res/picture/上传资料.png)

知识库页面支持：

- PDF
- DOCX
- TXT
- Markdown

文档生成入口还支持 PPTX。若知识库上传不接受某个文件，请先转换为支持格式。

### 9.3 查看知识库状态

知识库页面会显示：

- 知识条目数量。
- 已导入文档数量。
- 正在处理的文档数量。

文档处理完成后，状态会变为“就绪”。

### 9.4 预览文档

1. 在已导入文档列表中找到目标文档。
2. 点击“预览”按钮。
3. 页面会弹出文档片段预览。
4. 查看后点击关闭。

![图 18 预览知识库文档](../res/picture/预览知识库文档.png)

### 9.5 删除单个文档

1. 在文档列表中点击删除按钮。
2. 系统会询问是否确认删除。
3. 确认后，该文档会从知识库中移除。

### 9.6 清空知识库

1. 当知识库中已有文档时，页面会显示“清空知识库”按钮。
2. 点击后，系统会再次确认。
3. 确认后，所有已导入文档都会被删除。

清空操作不可恢复，请谨慎使用。

## 10. 使用 RAG 增强生成

RAG 增强可以理解为“让 AI 先参考资料，再帮你写大纲”。

### 10.1 什么时候建议开启 RAG

建议开启的情况：

- 你上传了课程资料、行业报告或项目文档。
- 主题需要专业术语和事实依据。
- 你希望内容更贴近自己的材料。
- 你需要比较正式的课堂汇报或课程项目展示。

可以关闭的情况：

- 只是快速生成一个普通大纲。
- 网络较慢。
- 主题很简单，不需要额外资料。

### 10.2 如何开启

1. 点击“开始生成”或“创建”。
2. 选择“主题生成”。
3. 找到“混合 RAG 增强”开关。
4. 打开开关后点击“生成大纲”。

提示：文档生成模式本身会使用你上传的文档内容，因此页面主要在主题生成模式中显示 RAG 开关。

## 11. 常见使用流程

### 11.1 快速做一份普通 PPT

1. 打开网站。
2. 注册并登录。
3. 点击“开始生成”。
4. 选择“主题生成”。
5. 输入 PPT 主题。
6. 点击“生成大纲”。
7. 在大纲编辑器中检查内容。
8. 点击“生成 PPT”。
9. 查看生成结果。

### 11.2 用课程资料生成 PPT

1. 登录账号。
2. 进入“知识库”。
3. 上传课程资料或参考文档。
4. 回到首页，点击“开始生成”。
5. 输入 PPT 主题。
6. 开启“混合 RAG 增强”。
7. 点击“生成大纲”。
8. 编辑大纲并生成 PPT。

### 11.3 把已有文档变成 PPT

1. 点击“开始生成”。
2. 选择“文档生成”。
3. 上传 PDF、DOCX、PPTX、TXT 或 Markdown 文件。
4. 点击“生成大纲”。
5. 检查并修改大纲。
6. 点击“生成 PPT”。

### 11.4 修改已经保存的大纲

1. 点击“我的大纲”。
2. 搜索或找到目标大纲。
3. 点击进入编辑。
4. 修改页面内容或顺序。
5. 点击“保存”。
6. 如需更新 PPT，点击“生成 PPT”。

## 12. 常见问题

| 问题 | 原因 | 解决办法 |
| --- | --- | --- |
| 不能保存大纲 | 可能未登录或登录状态过期 | 重新登录后再保存 |
| 生成大纲失败 | 主题为空、网络异常或 AI 服务暂时不可用 | 检查主题，稍后重试，或关闭 RAG |
| 生成时间较长 | RAG 会检索知识库和网络资料 | 等待完成，或关闭 RAG 快速生成 |
| 上传资料失败 | 未登录、文件格式不支持或文件读取失败 | 登录后重试，换成 PDF/DOCX/TXT/Markdown |
| 找不到大纲 | 搜索关键词不匹配 | 清除搜索后重新查看列表 |
| 删除后想恢复 | 删除操作不可恢复 | 删除前请确认，重要内容可先下载 Markdown |
| 手机上编辑不方便 | 大纲编辑字段较多 | 建议用电脑浏览器编辑复杂 PPT |

## 13. 使用建议

- 主题写得越清楚，生成的大纲越贴合需求。
- 如果是课程汇报，建议在主题中写明课程、受众和汇报目标。
- 如果有老师给的资料或项目文档，先上传到知识库，再开启 RAG。
- 生成后一定要检查大纲，不要直接把 AI 内容当成最终稿。
- 复杂页面建议分成多页，不要把太多内容塞进一页。
- 删除大纲或知识库文档前，先确认不再需要。
