# Knowledge Base Workspace

This directory stores domain documents, RAG preparation notes, experiment plans,
and report assets for the technical validation report.

## Directory layout

- `Software Engineering/`
  - `source_docs/`: Original public documents or source references for software engineering.
  - `processed_notes/`: Cleaned notes, chunking drafts, and RAG-ready summaries.
  - `metadata/`: Source metadata, authority notes, and usage mapping.
- `Alzheimer Disease/`
  - `source_docs/`: Original public documents or source references for Alzheimer's disease.
  - `processed_notes/`: Cleaned notes, chunking drafts, and RAG-ready summaries.
  - `metadata/`: Source metadata, authority notes, and usage mapping.
- `Football/`
  - `source_docs/`: Original public documents or source references for football.
  - `processed_notes/`: Cleaned notes, chunking drafts, and RAG-ready summaries.
  - `metadata/`: Source metadata, authority notes, and usage mapping.
- `Experiment Design/`
  - Test inputs, prompt variants, schema constraints, scoring rubrics, and model comparison plans.
- `Report Assets/`
  - Experiment result tables, chart data, generated figures, and final report assets.

## Review gates

1. Confirm this directory structure.
2. Collect and review source documents for the three domains.
3. Prepare RAG-ready metadata and chunking guidance.
4. Design and execute pure LLM vs. RAG experiments.
5. Build evaluation tables, charts, and the final PDF report.
