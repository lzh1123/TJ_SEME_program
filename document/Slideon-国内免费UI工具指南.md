## 🔧 高级技巧

### 1. 自动布局 (Auto Layout)

**使用场景**：按钮组、卡片列表、导航栏

**操作步骤**：
1. 选中多个元素
2. 点击右侧「自动布局」按钮（或按 `Shift + A`）
3. 设置方向（水平/垂直）
4. 设置间距（8px/16px/24px）

### 2. 组件变体 (Variants)

**使用场景**：按钮的不同状态（默认、悬停、禁用）

**操作步骤**：
1. 创建基础组件
2. 点击「创建变体」
3. 添加属性（如：状态=默认/悬停/禁用）
4. 修改每个变体的样式

### 3. 原型交互

**操作路径**：顶部「原型」标签

**常用交互**：
- 点击跳转：选择元素 → 拖拽箭头到目标画板
- 悬停效果：设置「悬停」触发 + 「打开覆盖层」
- 滚动效果：设置「滚动时」触发 + 「移动」动画

### 4. 设计交付

**操作路径**：「分享」→ 「复制链接」

**设置选项**：
- 查看权限：任何人可查看 / 仅团队成员
- 允许评论：是 / 否
- 允许导出：是 / 否

### 使用约束 (Constraints)

**操作路径**：选中元素 → 右侧「约束」

**常用设置**：
- 左右固定：元素随宽度缩放
- 顶部固定：元素保持顶部距离
- 居中：元素始终居中

## 🚀 导出与分享

### 1. 导出图片

**操作路径**：选中元素 → 右键 → 「导出」

**推荐设置**：
- 格式：PNG（界面）/ SVG（图标）

**查看方式**：
- 选中元素查看CSS代码
- 查看间距和尺寸
- 复制颜色值和字体样式
