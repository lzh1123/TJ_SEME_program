# Milvus-Stonealone

- Windows 环境启动 Milvus-Stonealone 进行测试。

```powershell
./standalone.bat start
```

- Windows 环境停止 Milvus-Stonealone 

```powershell
./standalone.bat stop
```

- Windows 环境重启 Milvus-Stonealone 
```powershell
./standalone.bat restart
```

- Windows 删除 Milvus-Stonealone 数据(慎用)
```powershell
./standalone.bat delete
```
